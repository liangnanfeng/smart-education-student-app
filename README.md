# 数智教育学生端

面向小学生的移动端 Web 学习应用原型。项目围绕“知识、测试、成长、AI 伙伴”四个体验方向设计，包含 1–2、3–4、5–6 年级三组课程与闯关内容。

## 运行

在本目录执行：

```powershell
npm install
npm run dev
```

终端会输出本地预览地址。生产构建和测试命令：

```powershell
npm test -- --run
npm run build
```

## 已实现

- 登录、注册、找回密码与未满 14 周岁监护人授权流程。
- 首页、知识、测试、我的四项底部导航，以及 1–2、3–4、5–6 年级的课程分组。
- 知识课程的漫画、图文与视频学习入口；测试的主题闯关地图、进度与奖励反馈。
- 我的页面中的成长安排、能力画像、称号、勋章、错题本、作品工作台和设置入口。
- 积分商城与“我的搭配”，支持选择 AI 伙伴形象、服饰和装饰，并同步到应用内伙伴入口。
- 可拖动的 AI 伙伴：轻触查看提示、长按进行受限的语音问答演示，并在测试地图中跟随当前关卡。
- 积分、勋章、学习进度和偏好使用浏览器本地状态保存，便于原型演示。

## 原型边界

本项目目前仍是前端交互原型：真实账号、验证码、摄像头、扫码、语音识别、云同步、内容审核、作品发布、排行榜、支付及生产级 AI 服务需要在后续接入后启用。项目不会在浏览器本地保存密码、验证码、出生日期、手机号、邮箱或监护人授权表单值。

## 隐私边界

原型不会把密码、验证码、出生日期、手机号、邮箱或监护授权表单值写入 `localStorage`。演示偏好可通过清除浏览器站点数据移除。
